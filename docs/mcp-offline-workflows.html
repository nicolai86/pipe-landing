100% Offline AI Automation for 4-Axis Rotary Plasma

Modern AI coding assistants (Claude Desktop, Cursor, VS Code, LM Studio) can write scripts, generate code, and answer questions. But on the shop floor, fabricators and machine operators face two hard requirements: privacy (never uploading proprietary CAD or defense/motorsport weldment files to third-party cloud servers) and reliability (cutting parts even when the shop internet goes down).

RotaryCAM solves this with a standalone, native Model Context Protocol (MCP) stdio server: rotarycam-mcp. It runs completely offline on your local machine across macOS, Linux, and Windows, exposing 19 first-principles tools directly to your AI assistant:

  • 1. First-Principles Drive Math (rack_pinion_travel, lead_screw_travel, rotary_travel): Calculate pitch diameters, travel per revolution, motor steps/unit, maximum velocity, and acceleration directly from physical gearbox ratios, pinion modules, and ballscrew pitches—eliminating trial-and-error magic numbers.
  • 2. Headless STEP B-Rep CAD Analysis (analyze_step): Parse 3D CAD assemblies locally. Identify hollow structural profiles (round, square/rectangular HSS, angle iron, C-channel), extract true wall thickness and outer dimensions, and classify all cut features (STARTCUT, ENDCUT, holes, notches).
  • 3. Dual-Curve Zero-Bevel Compensation (apply_zero_bevel): Automatically detect angled saddle joints and copes on round tube. Calculate the 3D intersection curves between the outer and inner tube walls and apply zero-bevel torch compensation at your chosen intensity (e.g., 60%) to prevent inside weld-prep gouges.
  • 4. Shop-Ready G-Code & Multi-Stick Nesting (generate_gcode): Emit production-ready G-code programs with SimCNC 4D velocity scaling, trajectory-synchronized torch firing (M62/M63 P1), and 1D bin packing across standard raw stock stick lengths.
  • 5. Visual 3D Handoff (open_in_rotarycam): Hand off the active part directly to your browser for visual 3D WebGL inspection and simulated toolpath verification before striking the arc.
Transport Protocol Standard JSON-RPC 2.0 over Stdio
Cloud Dependency Zero (100% Offline & Air-Gapped)
Supported Clients Claude Desktop, Cursor, VS Code, LM Studio
Step 01

Locate the Binary & Activate Offline License (rotarycam.lic)

The standalone rotarycam-mcp executable is bundled directly inside your RotaryCAM application directory. No separate runtime, Python environment, or external package manager is required.

  • Binary Locations by Platform:
    • macOS: /Applications/RotaryCAM.app/Contents/MacOS/rotarycam-mcp (or ./dist/bundle/rotarycam-mcp in source builds)
    • Windows: C:\Program Files\RotaryCAM\rotarycam-mcp.exe
    • Linux: /opt/RotaryCAM/rotarycam-mcp
  • Offline License Activation: Place your signed rotarycam.lic license file in the same directory as the rotarycam-mcp executable. When the server launches, it detects the cryptographic Ed25519 token locally and unlocks all Pro features (dual-curve zero-bevel compensation, multi-stick pack nesting, and custom machine kinematics) without requiring an internet connection.
Terminal / Shell Verification 
# Test that rotarycam-mcp starts and reports version
$ ./rotarycam-mcp -v
rotarycam-mcp v0.3.2 (commit de808aa, built 2026-10-23, run local)

# Verify license discovery (auto-detects rotarycam.lic in current folder)
$ ./rotarycam-mcp -license ./rotarycam.lic
Step 02

Configure Claude Desktop (claude_desktop_config.json)

To give Anthropic's Claude Desktop direct control over RotaryCAM, add the server entry to your Claude Desktop configuration file:

  • macOS: ~/Library/Application Support/Claude/claude_desktop_config.json
  • Windows: %APPDATA%\Claude\claude_desktop_config.json
  • Linux: ~/.config/Claude/claude_desktop_config.json
claude_desktop_config.json 
{
  "mcpServers": {
    "rotarycam": {
      "command": "/Applications/RotaryCAM.app/Contents/MacOS/rotarycam-mcp"
    }
  }
}

Restart Claude Desktop. Look for the hammer (🔨) icon in the chat composer to verify that all 19 RotaryCAM tools are registered and ready.

Step 03

Configure Cursor IDE & VS Code

If you use Cursor IDE or VS Code with an MCP extension for shop automation scripts or CAD pipeline development:

  • 1. Open Cursor Settings: Press Ctrl + Shift + J (or Cmd + , on macOS) and navigate to Features → MCP Servers.
  • 2. Click "+ Add New MCP Server":
    • Name: rotarycam
    • Type: stdio
    • Command: /path/to/RotaryCAM/rotarycam-mcp (or C:\Program Files\RotaryCAM\rotarycam-mcp.exe on Windows)
  • 3. Refresh Connection: Click the green refresh button. The server indicator will turn green, indicating active communication with RotaryCAM's kinematics core.
Step 04

Air-Gapped Setup with Local Open LLMs (LM Studio / Ollama)

For complete air-gapped isolation in classified, ITAR, or remote job sites without internet, connect rotarycam-mcp to an open-weights model (such as Qwen 2.5 Coder or Llama 3.3) running locally via LM Studio:

  • 1. Open LM Studio: Navigate to the Developer / MCP tab in LM Studio.
  • 2. Add Stdio Server: Enter the absolute path to rotarycam-mcp.
  • 3. Full Air-Gap Execution: Because both the large language model and the CAD/CAM solver run on your local machine, geometry parsing, kinematics scaling, and G-code generation remain 100% on-premises.
Step 05

Calculate Kinematic Limits from Physical Drive Hardware

Setting axis velocity, acceleration, and jerk limits in CNC controllers usually involves guesswork and magic numbers. RotaryCAM provides first-principles drive math tools to compute precise physical limits directly from hardware specs:

Example: Rack-and-Pinion X-Axis Calculation 
// User asks: "My X axis uses a 3000 RPM servo, 10:1 planetary gearbox, and a 20-tooth Module 1.5 pinion.
// What are my travel per revolution and maximum linear velocity?"

// Assistant calls rack_pinion_travel:
{
  "module": 1.5,
  "teeth": 20,
  "gearbox_ratio": 10.0
}

// Tool output:
{
  "pitch_diameter_mm": 30.0,
  "pinion_circumference_mm": 94.248,
  "travel_per_motor_rev_mm": 9.425,
  "steps_per_mm_1000cpr": 424.413
}

// Assistant calls axis_max_velocity with 3000 motor RPM and 85% safety factor:
{
  "max_motor_rpm": 3000,
  "travel_per_motor_rev": 9.425,
  "safety_factor": 0.85
}

// Tool output:
{
  "theoretical_max_velocity_mm_min": 28274.3,
  "recommended_max_velocity_mm_min": 24033.2
}

Similar physics tools are available for ballscrews (lead_screw_travel), rotary chucks (rotary_travel), and S-curve jerk ramps (axis_jerk_from_ramp).

Step 06

Analyze STEP CAD Assemblies Headless (analyze_step)

Feed any 3D STEP file directly to the assistant. The underlying OpenCASCADE topology kernel inspects every solid body, identifies cross-section profiles, and classifies cut contours:

Example: analyze_step Tool Call 
// Assistant calls analyze_step:
{
  "path": "/Users/operator/Desktop/rollcage-main-hoop.step"
}

// Tool output:
{
  "process_id": "1B8C4779-9924-43AD-B636-7E1B4B829DEA",
  "total_solids": 2,
  "solids": [
    {
      "solid_id": "solid_1",
      "profile": "Profile_HSS_Round",
      "dimensions": { "od": 44.45, "inner_radius": 19.125, "thickness": 3.1, "length": 1820.0 },
      "features": [
        { "id": "feat_01", "type": "startCut", "is_cope_or_fishmouth": false },
        { "id": "feat_02", "type": "endCut", "is_cope_or_fishmouth": true, "x_center": 1812.5 }
      ]
    }
  ]
}

Notice how the engine automatically flags is_cope_or_fishmouth: true when an angled saddle joint or tube copes intersection is detected.

Step 07

Apply Dual-Curve Zero-Bevel Compensation (apply_zero_bevel)

When a perpendicular plasma torch cuts an angled fishmouth or saddle joint around a round tube, the back wall of the cut receives an inward bevel that leaves unwanted gaps during TIG or MIG fitup. RotaryCAM's Zero-Bevel Dual-Curve Compensation shifts the cutting path to the inner cylinder intersection:

Example: apply_zero_bevel Tool Call 
// Assistant calls apply_zero_bevel:
{
  "process_id": "1B8C4779-9924-43AD-B636-7E1B4B829DEA",
  "intensity": 60.0,
  "fade_angle": 90.0,
  "side_gap": 0.5
}

// Tool output:
{
  "process_id": "1B8C4779-9924-43AD-B636-7E1B4B829DEA",
  "intensity": 60.0,
  "applied_count": 1,
  "skipped_count": 1,
  "features": [
    {
      "feature_id": "feat_02",
      "feature_type": "endCut",
      "action": "applied",
      "reason": "Round stock cope/fishmouth cut compensated at 60.0% intensity"
    },
    {
      "feature_id": "feat_01",
      "feature_type": "startCut",
      "action": "skipped",
      "reason": "Straight 90 deg cut (not a cope or saddle fishmouth)"
    }
  ]
}

The engine automatically skips straight 90° cuts and applies compensation exclusively where dual-curve geometry is physically required.

Step 08

Generate Production G-Code & Inspect in 3D (generate_gcode & open_in_rotarycam)

Once cut features and compensations are configured, emit machine-ready G-code and immediately inspect the result:

Generating G-Code & Browser Handoff 
// 1. Assistant calls generate_gcode:
{
  "process_id": "1B8C4779-9924-43AD-B636-7E1B4B829DEA",
  "mode": "auto"
}

// Output:
{
  "status": "success",
  "files_written": [
    {
      "path": "/Users/operator/Desktop/pack_Profile_HSS_Round_OD44.5_stick1.nc",
      "line_count": 1562,
      "pieces_in_group": 2,
      "total_sticks": 1
    }
  ]
}

// 2. Assistant calls open_in_rotarycam:
{
  "process_id": "1B8C4779-9924-43AD-B636-7E1B4B829DEA"
}

// Tool output:
"Opened session 1B8C4779-9924-43AD-B636-7E1B4B829DEA in RotaryCAM viewport at: http://localhost:3000/process/1B8C4779-9924-43AD-B636-7E1B4B829DEA"

Your default browser automatically opens the RotaryCAM 3D viewport, displaying the exact toolpath, kerf offset, pierce locations, and animated 4-axis motion simulator.
