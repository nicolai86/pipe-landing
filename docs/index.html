Recommended First-Time Setup Sequence

If you are setting up Pipe CAM for a new rotary plasma table, start with Tutorial 01: Basic Machine Configuration and Tutorial 07: SimCNC Motion-Synchronized Torch & 3D Ramp Lead-Ins. Because Pipe CAM executes a deterministic physics-based S-curve velocity profiler and Tool Center Point (TCP) unwrap in software, entering your machine's true axis velocity/acceleration limits and wiring ExtTrajSyncOut0/1 (M62/M63 P0/P1) ensures your generated G-code runs at peak surface speed with zero-overburn early torch extinguish and spatter-free 3D ramp lead-ins.
