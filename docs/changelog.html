Instant Version Verification & Release Notes

Whether you are verifying that your shop station is running the latest CAM solver update, checking what new post-processor or CAD unfolding features were added in a recent release, or copying system diagnostics for support, the built-in About RotaryCAM dialog provides full build provenance and a chronological changelog in one click.

Step 01

Click ⓘ About in the Top-Right Header Bar

From anywhere in the Pipe CAM workspace, look at the top-right application header bar (next to ⚙ Machines):

  • Click the ⓘ About button in the top-right navigation bar (you can also click the version badge in the bottom-right status bar).
Step 02

Inspect Build Metadata, Release Changelog & Copy Diagnostics

The About RotaryCAM modal opens over the workspace and is divided into three sections:

  • 1. Build Metadata Table (Top): Displays the active Version (v1.0.0), exact Git Commit hash, Build Date (UTC), CI Build Run ID, host Platform (darwin/arm64), Build Mode, and current License Status.
  • 2. What Changed — Recent Highlights (Center): A scrollable, date-stamped engineering changelog detailing newly shipped capabilities—such as Simultaneous X/Y/A Pre-Pierce Positioning in G93 Mode, Tube Bending Quota & License Support, 3D Bent Tube "Cut-and-Bend" Unfolding, Straight HSS Cheek Cuts & 5-Zone Corner Relief, Multi-Stick Nesting .zip Export, and SimCNC 3.5 vs. 3.6 Beta Profiles.
  • 3. Copy Diagnostics (Bottom-Right): Click 📋 Copy Diagnostics to copy a formatted snapshot of your build metadata and environment to the clipboard when reporting an issue or requesting support.

🗓️ Current Release Changelog Entries

The built-in changelog view reflects all recent production engine updates. Below is the full transcript of recent engineering releases directly from the application:

🗓️ Oct 20, 2026 Cut-and-Bend Unfolding, Flat HSS Projection & Multi-Stick ZIP
  • Simultaneous X/Y/A Pre-Pierce Positioning in G93 Mode: On controllers supporting native G93 inverse-time feedrates (such as SimCNC 3.6), positioning moves between features now travel in X, Y, and A simultaneously in a single coordinated move rather than stopping between separate linear rapid and rotary indexing steps, while preserving split positioning for G94 controllers.
  • Tube Bending Quota & License Support: Added per-file and hourly bend entitlements across guest, signed-in, and licensed shop tiers (3 bends per STEP file for guests, 10 bends/hour for signed-in accounts, and 100 bends by default on customer licenses).
  • 3D Bent Tube “Cut-and-Bend” Unfolding: Automatic spine detection and unfolding of bent round pipes and square/rectangular HSS into straight-stock pie-cut relief patterns with an uncut extrados living hinge.
  • Straight HSS Cheek Cuts & 5-Zone Corner Relief: True-plane projection onto flat HSS walls (projectContourOntoHSSSurface) eliminating wavy bend lines on flat faces, with configurable relief cut counts, spine width, and inner-wall binding clearance.
  • 3D Bent Toolpath Preview & Collapsible Bend Groups: Renders relief toolpaths directly onto the 3D bent tube mesh and groups relief cuts under interactive Bend #N rows.
  • Multi-Stick Nesting .zip Export: Direct 📦 Download ZIP (N Sticks) buttons in the Pack toolbar, Stick Pager, and G-Code header with automatic G-code refresh on nesting edits.
  • SimCNC 3.5 vs 3.6 Beta Profiles & Instant Solid Matching: Dedicated SimCNC 3.5 (G94 + G93 Emulation) and SimCNC 3.6 Beta (G93 Inverse-Time) machine presets with seamless WebGL preservation on profile switch.
  • Configurable X-Axis Travel & Start Direction: Added Workpiece Moves on X (G92 X-L → X0, free-end to chuck) vs Torch Moves on X (G92 X0 → +max(X)) origin mode in machine kinematics, defaulting SimCNC profiles to workpiece-moving X.
🗓️ Oct 19, 2026 Standalone Offline Bundles & Persistent Workspace
  • Cross-Platform Offline Releases (Windows, macOS, Linux): Self-contained single-binary distribution (RotaryCAM) with embedded web assets and 100% offline Ed25519 license activation.
  • Persistent Session History: Automatically saves and restores processed STEP models, solid selections, and generated G-code across restarts.
  • Version & Build Diagnostics: Added the About dialog with Git commit hash, CI run ID, and one-click diagnostic clipboard export.
🗓️ Oct 16, 2026 G93 Inverse-Time Precision & 3D Stock Preview
  • G93 Inverse-Time & Dynamic THC Refinements: Eliminated circular lead-in/out micro-sliver feedrate spikes, unified G93/G94 preambles across Single-Part and Pack Mode, and deduplicated HSS corner THC lock macros.
  • 3D Uncut Stock Envelope & Simulator Plunge Fix: Added translucent 3D stock overlays and accurate SimCNC M3 vertical pierce-to-cut plunge in the 3D simulator.
